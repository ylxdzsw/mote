# Mote

A local-first demo exploring semantic text and anchor-relative spatial placement.

## Run

Use Node.js 22.12+ (or a current release) and npm.

```sh
npm install
npm run dev
```

Open the URL printed by Vite, normally `http://localhost:5173` (it selects the next port if occupied). The development server listens on all interfaces for previews; do not expose it as a production server. Keep the same origin between sessions to access the same local draft.

```sh
npm run check   # TypeScript
npm run build   # TypeScript + production bundle in dist/
npm run preview
```

## First working slice

- One V0 document, initially an editable example with three text-and-space sections, 27 main blocks, and five floating objects: three text notes, an image, and a table. Existing browser drafts are preserved; the small **Reset to example** button in the editing top bar loads the current demo after confirmation.
- Selectable semantic paragraph classes (`title`, `heading`, `body`, `caption`, `code`, `list`), an automatic table-only `table` class, and phrase classes (`primary`, `secondary`, `bold`, `term`). Primary and Secondary use distinct green and blue emphasis colors; Bold only overrides weight by default. Ctrl/⌘B toggles Bold in main text, floating text, and tables, but not Code. Bold HTML paste maps to this same semantic class. No direct selection styling.
- The editing toolbar has three persistent menus: current paragraph class, current inline class, and **+** for all insertable elements. Wider screens add Heading/List/Code, Bold/Primary/Secondary/Term, and Text box/Image/Rectangle/Line shortcuts. Paragraph shortcuts toggle back to Body; inline shortcuts toggle back to Plain. A mixed selection receives the chosen class throughout; menu choices always apply explicitly. Menus show icons or theme samples, support arrow keys/Home/End/type-ahead, and close with Escape or an outside click. List indentation commands are in the paragraph menu as well as on Tab/Shift+Tab. Shortcuts disappear in fixed width tiers, with Bold retained longest; 768–849px shows just the three menus and Undo/Redo. Table and Label have fixed paragraph indicators and disabled paragraph shortcuts; Code disables inline controls. Armed drawing tools highlight both **+** and their shortcut.
- A **Document** button opens a live right-side panel with Layout and Theme tabs, replacing the selection inspector while open. The inspector heading names the selected item type (Main text, Space, Floating text, Floating image, or Floating table), rather than repeating it in the toolbar. Its bottom **Edit style** section has separate paragraph and inline style buttons labeled for their target class (for example, **Heading style…** or **Bold style…**); they open the current paragraph class (Table in tables) or inline class (Primary for plain text) without changing the selection. There is no style-edit button in the toolbar. Selecting text does not switch or close the theme panel. **View** keeps browser-local preferences separate.
- Theme Defaults define base typography, text color, spacing, and page background. The fixed Title/Heading/Body/Caption/Code/List/Table and Primary/Secondary/Bold/Term classes can override their applicable properties, with inherited indicators, per-property resets, a class reset, and a small sample. Paragraphs support typeface, size, weight, color, line height, letter spacing, and spacing before/after. Font size and lengths offer **em** and **px**; line height also offers **×** the paragraph's font size. Every em is relative to the **Defaults font size**, not the local paragraph size. That baseline remains in pixels (initially 16px, with a default line height of 1.5em); preset class sizes, line heights, letter spacing, and paragraph spacing use em. Switching units preserves the current rendered length. Phrases support color, optional highlight, weight, italic, and decoration; unspecified properties follow surrounding text. Styles are shared by main text, floating text, Table-class cell text, and the minimap. No direct selection styling or custom classes.
- **Code** is a plain-text paragraph/block with a monospace default and preserved whitespace. Enter and Shift+Enter insert a newline within the block, Tab inserts two spaces, and Ctrl/⌘Enter inserts a Body paragraph after it. Backspace at the block start returns it to Body. Code strips phrase marks and pastes plain text; line breaks survive changing the class back to Body. Code typography is controlled centrally by its theme class.
- **List** is an independent unordered-list item, not a child of a list container. Enter splits it into a new same-level item, including when the item is empty. Shift+Enter adds a line aligned with the item's text start. Tab / Shift+Tab or the toolbar arrows indent/outdent selected items independently, without changing neighboring items. Backspace at the start reduces one level; at the top level it returns the item to Body without deleting its text. Each level adds 24px indentation, never a font-size change. Top-level markers are solid dots; all sublevels use hollow dots. Pasted unordered lists flatten into independent paragraphs; ordered-list paste becomes Body text. Code and List work in main and floating text, while tables always use Table.
- Explicit vertical spacers and continuous text segments (runs of paragraphs between spaces) have shared draggable horizontal boundaries. Drag a boundary to resize the section above it; following content and its anchored objects move with the flow. Spaces retain a 24px minimum. Text segments start at automatic height; extending one saves a minimum, not a fixed height. Shorter content keeps the reserved room. When natural content reaches or exceeds that minimum, or the boundary is dragged back to the content, the minimum is cleared and automatic sizing resumes. Text cannot be clipped by shrinking its segment. Boundaries also support Up/Down (Shift for 1px) and Home to restore automatic text height or the minimum spacer height.
- Rich-text floating boxes anchored to main-text blocks. Drag the **top, left, or bottom border to move**, and the **right border to resize**; click inside to edit text. There are no delete buttons, corner resize handles, or anchor markers. Focused objects move with arrow keys (Shift for 1px); their right borders support left/right arrows for width. Press Delete/Backspace with the outer object focused to remove it after confirmation.
- Floating images share the same anchor, drag, resize, and delete behavior. Choose a local PNG, JPEG, WebP, GIF, or AVIF (up to 10 MB); images are embedded in the browser-local draft, never uploaded. Resizing preserves proportions. Select an image to edit its accessible description or replace its file in the sidebar.
- Floating tables are directly editable: click a cell, use Tab / Shift+Tab to navigate, and add/remove rows or columns through the sidebar. Every cell uses the global **Table** paragraph class, independent of Body but with the same preset. Table is available in the theme editor and through **Table style…**, never in the normal paragraph-class dropdown; the toolbar shows a fixed Table label inside cells. **Primary**, **Secondary**, **Bold**, and **Term** phrase classes remain available. Each cell contains exactly one paragraph: Enter, Shift+Enter, and Ctrl/⌘Enter insert soft newlines, not paragraph spacing. Pasted paragraphs/headings and existing multi-paragraph cells flatten to newlines while preserving text and inline classes. Pasted table/spreadsheet ranges still fill separate cells. Tables support cell selection, rich-text paste, and document-wide undo/redo for text and row/column changes. The last row and column cannot be removed through the sidebar; delete the floating object to remove the entire table.
- Rectangles, ellipses, lines, and labels are regular floating-object kinds, sharing anchoring, movement, selection, marquee selection, grid snapping, ordering, persistence, undo, zoom, and minimap behavior with text, images, and tables. Rectangles can be square or rounded; ellipses can be circles; both have per-object fill/stroke colors, width, and Solid/Dashed outlines. Lines can be straight or simple elbow routes, have per-object stroke settings, arrows at either end, draggable endpoints, and optional connections to floating objects. Default strokes follow the Defaults font color; shape fill defaults to None. Labels are single-paragraph rich text using the fixed Label class, never wrap automatically, and can attach to object center/top/bottom or to line center/left/right/above/below positions. Double-clicking an attachable object selects or creates its label; labels can be detached and remain independently movable. Enter finishes label editing and Shift+Enter inserts a soft break.
- A 16px dot grid appears behind every explicit space segment only while dragging or resizing floating objects, including dragging to create an object and resizing table columns. Selection, text editing, hover, and marquee selection do not show the grid. Objects snap to it while inside spaces; Alt bypasses snapping but not page boundaries. The grid is not shown in text-segment room, reading mode, or the minimap. Space backgrounds use the normal arrow cursor. Dragging unoccupied space starts a rectangular marquee that can select any floating kind; Shift adds to the selection. Transparent shape interiors are click-through, while filled shapes and images can be moved from their interiors. Marquee and group movement preserve relative positions, and attached line endpoints/labels follow their targets.
- **Table columns** resize by dragging internal dividers, adjusting only the two adjacent columns while preserving total table width. The outer right border resizes the whole table proportionally. Dividers support Left/Right arrows (Shift for 1px), a 40px minimum where space permits, and Escape cancellation; zoom/mode changes cancel an active drag. Drag previews are transient and each release is one undo step. **Left / Center / Right** in the inspector aligns the entire column containing the caret, or all columns intersecting a rectangular selection. Mixed alignment leaves all three buttons inactive. New columns start left-aligned with an equal-share weight; adding/removing columns preserves the relative widths of surviving columns. New rows follow existing column alignment.
- Configurable document width (320–2400px, initially 800px) and left/right main-text margins (initially 55px). Margins can be linked or edited independently and always leave at least 120px for text. The page remains continuous with fixed top padding and no automatic bottom padding, minimum page height, or branding footer. Its bottom follows the last main-text block or lowest floating object; explicit spaces and reserved segment heights are retained. Changes are immediate and locally saved, with no Apply/Cancel stage.
- One chronological undo/redo history covers text across editors, semantic-class application, table structure, layout/theme changes, spacers/segment resizing, and floating-object creation/deletion/geometry/image changes. Numeric-field focus sessions, color adjustments, and continuous typing are grouped; each released border drag is one step. Toolbar Undo/Redo and Ctrl/⌘Z / Ctrl/⌘Shift+Z (also Ctrl/⌘Y) work across editor focus and panel closing. Text/numeric settings inputs keep native input undo. History keeps up to 100 steps in memory and is cleared on reload or confirmed Reset to example; saved documents do not contain history.
- A live minimap on the left of the canvas shows text, semantic colors, whitespace, and floating boxes. Click a region to navigate or drag the shaded viewport to scrub vertically; horizontal position and editor selection are preserved. Wheel scrolling and keyboard arrows, Page Up/Down, Home/End work over the minimap. There is no hover popup. Native canvas scrollbars are hidden; wheel, touch, and trackpad scrolling remain available.
- Small main-text heading bookmarks sit to the right of the minimap in a 64px overlay (44px on mobile when explicitly shown), with 9px text. Labels take no horizontal layout space and can overlap the centered document; gaps between labels let clicks through. Floating notes remain visible in the miniature but do not contribute bookmarks. The current heading changes at a focus line 15% down the canvas viewport, capped at 120px; clicking a label aligns its heading to that line without changing horizontal position or text selection. Labels follow live edits and the miniature's scroll position; nearby labels spread out to stay readable. A very dense bookmark overlay can scroll independently over its labels. Full heading text is available in each label's tooltip and accessible name.
- Global settings under **View** offer faithful-proportion (default) and fit-whole-document minimap sizing, plus automatic/show/hide visibility. Automatic hides at viewport widths of 1050px and below, including mobile. Reading mode exposes these settings through **View**. Preferences live in browser-local storage, separately from the V0 document.
- Fixed app frame with independently scrolling document canvas and settings. Zoom controls live in the top bar between save status and the mode selector. Click the current percentage to select 25%, 50%, 75%, 100%, 125%, 150%, 200%, or 300% (plus Fit in reading mode). Zoom only the document using these controls, Ctrl/⌘ + wheel, pinch, or Ctrl/⌘ +/−; Ctrl/⌘ 0 resets the view. Incremental zoom snaps to 100% around actual size; continued zooming moves past it. Fit and explicit presets stay exact. Zoom is view state, not saved document geometry.
- Desktop editing/reading modes; viewports under 768px are reading-only. Entering reading mode fits the entire page width to preserve spatial relationships; document zoom remains available.
- A single browser-local draft in IndexedDB, written after each document update. Save errors are visible and retryable. Ctrl/⌘S is a no-op throughout editing and reading modes, including settings fields; it does not open the browser Save dialog or change the document.

Click a main-text block before inserting Space, Text box, Image, or Table through **+** or an available shortcut. Spaces and draggable boundaries span the page, including its text margins. Only the hovered segment's shared boundaries appear; hovering a floating text box, image, or table reveals the segment containing its anchor instead of the segment beneath the pointer. Document-top anchors have no segment to highlight. Keyboard-focused and actively dragged boundaries also remain visible. Top and bottom lines share the same thin, pixel-aligned rendering. Press inside a space to select it immediately, without temporarily selecting adjacent text, and adjust its height in the settings panel, or drag its lower border. Floating text and tables use the same inline semantic toolbar and theme as main text. Clicking an image selects it without moving it; movement is border-only.

## Model and boundaries

`MoteDocument` contains a `version: 'V0'`, width, left/right margins, theme defaults and class overrides, main-text editor JSON, and floating objects. Each main-text block has a stable UUID. Each floating object stores an anchor UUID (or a document-top null anchor), absolute document-space x, nonnegative anchor-relative y, width, and Overlap/Repel text-flow behavior where applicable. Text/table objects store constrained rich-text content; images store an embedded source and accessible description; rectangles and ellipses store height, fill, stroke, stroke width, dash style, and rectangle corner style; lines store two anchor-relative endpoints, optional object connections, route, bend, arrowhead settings, and stroke settings; labels store constrained rich-text content and an optional attachment. A label is a single paragraph with fixed `label` semantics. Attached geometry is derived from current target layout, not saved as an absolute page position. An omitted kind denotes a text box. Tables have their own constrained schema: one table, exactly one paragraph per cell, no editable paragraph semantic attribute, and the shared inline semantic mark. The table node stores a `columns` array of `{ width, align }`, with normalized proportional widths and left/center/right alignment. An absent array means equal-width, left-aligned columns. Column commands update structure and metadata in one transaction; rectangular paste extends metadata when it grows the table. Rendering uses a colgroup and column-wide cell decorations, with noneditable divider controls excluded from the minimap. Images use their intrinsic aspect ratio; tables grow vertically with their cell content.

Code and List retain the flat `paragraph` node and stable block UUIDs. A list paragraph stores `semantic: 'list'` and a zero-based `listLevel`; there are no list containers, ownership relationships, or nested item nodes. Code stores `semantic: 'code'` and unmarked text/soft breaks, rendered as `pre > code`. These blocks participate in the existing anchor, repulsion, segment-sizing, minimap, persistence, and shared undo systems.

The main editor's document node stores `minSegmentHeight` for the leading text segment; each spacer stores the same optional attribute for the following text segment, separately from its own `height`. `null` means automatic. This keeps a segment's minimum stable when paragraphs are inserted or deleted. Inserting a spacer leaves the preceding segment's minimum with that segment and starts an automatic segment after the new spacer. Removing a spacer joins the adjacent text runs, retaining the earlier run's minimum unless the combined content has already reached it. Runs with no paragraphs discard their minimum; an empty paragraph still counts as text. Heights include normal paragraph spacing and are measured in document pixels, with a 0.1px rounding tolerance for returning to automatic. Text growth, theme changes, and page-width reflow can all release a minimum.

Resize previews use transient editor decorations; only the released height is saved, and Escape/pointer cancellation restores the previous layout. Each committed boundary resize is one document undo step. Automatic release is a layout normalization folded into the triggering change, not a separate undo step. Undoing a width or theme change restores any segment minimums that change released, including the leading segment’s document-node attribute. Simply shrinking text after a release does not resurrect the old minimum.

When an anchor is deleted, its floating objects move to the closest surviving preceding block, or the document-top origin. Their content is retained. The shared history restores document snapshots and editor selections without stealing focus or undoing view preferences. Reset to example remains confirmed and clears history. V0 has no compatibility or migration promises yet.

IndexedDB (`mote-local` → `drafts` → `current`) is origin-specific local storage, not a backup. Another browser, port, hostname, or device has a different draft. Clearing site data removes it, and browsers may evict it. There is no cloud sync, multi-tab conflict resolution, import/export, or document library.

The floating layer deliberately permits overlap. Pointer and keyboard movement, duplication, and resizing stop at the document's horizontal edges; group movement preserves relative positions and accounts for attached labels. Changing document width does not rewrite saved offsets, and shrinking the page or growing unwrapped label text can still leave existing content outside its bounds. This demo does not yet have collision avoidance or a full spatial layout inspector.

## Structure

```text
src/app/        application shell, controls, responsive styles
src/document/   V0 data model, example, IndexedDB
src/editor/     constrained Tiptap schema and editor component
src/canvas/     anchor measurement, floating text interaction, zoom, minimap
src/theme/      shared semantic theme variables and controls
```

The minimap shares the rendered page through an inert, noneditable DOM snapshot, with editing controls and accessibility duplicates removed. Both sizing modes share this renderer and navigation geometry. Proportional mode keeps the page's aspect ratio and scrolls the miniature for long notes; fit mode compresses only the vertical axis as needed. Main-document zoom changes the viewport indicator, not miniature content scale. Scroll-only updates translate the existing snapshot and indicator; layout/content changes refresh the snapshot once per animation frame.

## Deployment

The current demo is live at **https://mote.ylxdzsw.com**. It is served as static files by Nginx from `/var/www/mote`, with the virtual host in `/etc/nginx/conf.d/mote.conf`. The existing wildcard Cloudflare Origin CA certificate covers the hostname. It is intentionally public and unauthenticated: there is no server API, session, account, or cloud document storage.

The deployment sets `Cache-Control: no-store` and disables Nginx ETags/expiration for HTML, JavaScript, CSS, and fallback responses. Cloudflare receives the origin directive and currently reports `DYNAMIC`/`BYPASS`, so the pre-release build is not cached at the edge. There is no service worker. Intentional IndexedDB document persistence is separate from HTTP caching. Future updates require `npm run build`, copying `dist/` to `/var/www/mote`, then `nginx -t && systemctl reload nginx`.

Vite development and preview responses also send `Cache-Control: no-store`. `public/_headers` carries the same rule for static hosts that support that format. Other hosts must explicitly set `Cache-Control: no-store` on **all** responses, including HTML and built assets.

Review the early-development decisions in `.mu/AGENTS.md` before a release.
